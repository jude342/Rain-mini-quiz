# Core Values Quiz 💗

A small interactive study website based on the uploaded NCM 104 lesson:
**Nursing Core Values as a Community Health Nurse**

## Files
- `index.html` — quiz, results, review, and interactions
- `style.css` — all styling and animations

## How to use
Open `index.html` in a browser. No backend, build step, npm, or database is required.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `style.css`.
3. Go to **Settings → Pages**.
4. Choose the `main` branch and `/root`.
5. Save and open the generated Pages URL.

The quiz content is based on the provided lesson and includes 15 practice questions.
